    System requirements

    Build from source (Visual Studio 2022 and CMake)

    You need Visual Studio 2022 or newer with the Desktop development with C++ workload, and CMake 3.25 or newer. From a Developer PowerShell for VS:

    git clone https://github.com/danielalyoshin/knobs.git
cd knobs
cmake --preset x64
cmake --build --preset release

    Then run build\x64\Release\knobs.exe. The README has the full instructions and the tests.

    How it works

    More in the README on how it works

    In the tray, from sign-in
    knobs starts with Windows and stays out of sight in the tray while it works. A notification says when something needs you.
    Read-only on OBS
    knobs never writes to OBS’s settings or its install. The install stays unlocked, so a running knobs never blocks an OBS update.
    No telemetry, no account
    knobs collects nothing. It goes online only if you turn on its update check, which asks GitHub for the latest version once a day. A VST plugin that goes online (to check its licence, say) does so whether it runs in knobs or in OBS.

    Benchmarks against OBS

    Same sound

    For the same input, knobs’s output is bit-identical to OBS’s: not one bit of the audio differs. A test tool, knobs-compare, checks this against OBS itself.

    Same delay

    From the mic to the cable, with both sending into the same cable.

    A fraction of the footprint

    knobs running a four-filter chain (3-Band Equalizer, Expander, Compressor, Limiter), against OBS minimized on the same PC. Memory is the working set: the RAM each one is using.

    Questions

    The sound

    Does knobs change how my mic sounds?

    No. knobs runs OBS’s own filter code, from your OBS install, with your settings. For the same input, its output is bit-identical to OBS’s: not one bit of the audio differs. NVIDIA’s noise removal behaves the same as it does in OBS.

    Which filters does it run?

    OBS’s built-in audio filters: Noise Suppression, Noise Gate, Expander, Upward Compressor, Compressor, Limiter, Gain, 3-Band Equalizer and Invert Polarity. Also VST 2 plugins, as OBS hosts them, and NVIDIA’s noise removal, which needs an NVIDIA RTX GPU and NVIDIA’s Audio Effects SDK, as it does in OBS.

    Setting up

    Does OBS have to stay open?

    No. knobs runs your chain with OBS closed or open, so your other apps keep your mic while you stream. If OBS’s Audio Monitoring also plays your mic into knobs’s cable, knobs pauses while OBS is open instead, so the cable doesn’t get your mic twice. You can change this with Pause while OBS is open in knobs’s tray menu.

    Which virtual cable do I need?

    Any of them. A virtual cable is a sound device that exists only in software: knobs plays your mic into it, and your other apps choose it as their mic. knobs’s installer can install VB-CABLE for you. knobs recognizes VB-Audio’s cables and Virtual Audio Cable, and can use any other playback device too.

    What if something doesn’t work?

    Check Known limits in the README first. If your problem isn’t there, open an issue on GitHub and attach knobs’s log, from Open log folder in its tray menu. Look the log over first: it names your audio devices and folders on your PC.

    The project

    Does knobs collect anything?

    No. knobs has no telemetry and no account. It goes online only if you turn on its update check, and your mic’s audio stays on your PC. A VST plugin that goes online (to check its licence, say) does so whether it runs in knobs or in OBS.

    Is knobs made by the OBS Project?

    No. knobs is an independent project, not affiliated with the OBS Project.

    Is knobs free?

    Yes. knobs is open source, under GPL-2.0-or-later, the same licence as libobs, OBS’s core library.
